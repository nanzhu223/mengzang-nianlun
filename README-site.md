# 触摸年轮 · 蒙藏学校旧址中华民族共同体数字记忆

> 参赛赛道：指定命题“红色之旅 追梦铸魂”作品赛项
> 作品形态：**网站（主体）＋ 智能体“问枣树”（创新点）＋ 演示视频 ＋ 作品说明**

以北京市西城区小石虎胡同 33 号蒙藏学校旧址西院那棵**始植于清初、树龄近 400 年的大枣树**为叙事者。
把它的年轮做成时间轴：**每一圈对应一个关键历史节点，点击年轮即“进入”那个年代**，听枣树用第一人称讲述它亲眼所见的事。

核心叙述：**红色火种点燃民族觉醒，新时代铸牢中华民族共同体意识。**

## 一、快速开始

### 方式 A：直接打开（零依赖，离线可用）

双击 `index.html` 即可。所有页面、年轮交互、史料检索、智能体“问枣树”均为纯前端实现，无需联网与后端。

> 建议用 Chrome / Edge 打开。若通过 `file://` 打开时浏览器限制了某些能力，可用方式 B。

### 方式 B：本地服务（推荐，下面板“问枣树”可调用真实 RAG 接口）

```bat
:: Windows 双击运行
start.bat
```

或手动：

```bash
pip install -r requirements.txt      # 只需 flask
python server.py                     # http://127.0.0.1:8000
```

### 方式 C：部署上线

纯静态部分（HTML/CSS/JS）可直接放到任意静态托管（GitHub Pages / Nginx / 校园服务器）。
如需智能体后端，把 `server.py` 部署到任意支持 Python 的服务器即可（`index.html` 等仍由它托管）。

## 四、内容维护：只改 `assets/js/data.js`

全站文字、年轮节点、人物、史料、来源都在 `assets/js/data.js` 一个文件里，改完刷新页面即可生效。

**新增一个年代节点**（会同时出现在首页年轮、时间轴、史料库、智能体中）：

```js
{
  id: 'y1931',                 // 页面地址：era.html?era=y1931
  year: '1931', yearNum: 1931, yearLabel: '1931 年',
  ring: '外圈 10',             // 年轮标注
  title: '事件标题',
  event: '一句话事件概述',
  hue: 20, theme: '主题词',     // hue 控制该页示意插画色调
  scene: { caption: '场景图说明', source: '图片与史实来源' },
  monologue: '枣树第一人称独白（200—300 字）',
  facts: [ { text: '史料原文/摘录', source: '出处' } ],
  objects: [ { name: '物件', text: '说明' } ],
  people: ['ldz'],             // 关联人物 id，可点击
  keywords: ['关键词']
}
```

**新增史料条目**：在对应年代的 `facts` 中增加一条（自动进入史料库与智能体知识库）。
**新增人物**：往 `PEOPLE` 追加对象，并在 `RELATIONS` 中补充关系连线。

> 后端语料同步：改完 `data.js` 后运行 `node tools/export-corpus.js` 重新生成 `assets/data/corpus.json`。

## 五、智能体“问枣树”（RAG 架构）

- **人设**：一棵见证了中国近现代史近 400 年的枣树，语气温和、有历史感但不说教，以第一人称“我”说话。
- **知识库**：`data.js` 中的史料库（24 条，逐条带出处）、10 位人物档案、11 段枣树独白。
- **检索层**：中文 n-gram（2–4 元）加权召回 + 同义词扩展（如“多老/树龄”→“清初 400 年”），IDF 加权打分。
- **生成层**（三种模式，通过 `assets/js/agent-config.js` 切换）：
  1. `local`（默认）：本地“枣树语气”生成器，答案严格取自召回史料，离线可用，并列出引用与对应年代链接；
  2. `backend`：调用 `POST /api/ask`，由 Python 后端执行检索 +（可选）大模型生成；
  3. `llm`：浏览器直连 OpenAI 兼容接口，把召回史料作为上下文注入提示词，同样强制回引出处。
- **防幻觉约束**：提示词明确“只能依据提供的史料回答，不得编造史实、年份、人名或引文；不确定就说‘这个我记不清了’”，回答末尾强制列出来源。
- **引导探索**：回答末尾给出“进入 XX 年轮 →”链接，可跳转到对应年代页继续探索。

### 启用后端 RAG

```bash
python tools/export-corpus.js       # 或 node tools/export-corpus.js 先同步语料
python server.py                    # http://127.0.0.1:8000
```

然后在 `assets/js/agent-config.js` 中设置：

```js
window.NIANLUN_AGENT_CONFIG = { mode: 'backend', backend: 'http://127.0.0.1:8000/api/ask' };
```

### 接入大模型（可选）

```bat
set OPENAI_API_KEY=sk-xxxx
set OPENAI_BASE_URL=https://api.openai.com/v1
set OPENAI_MODEL=gpt-4o-mini
python server.py
```

未配置密钥时，`/api/ask` 自动回退为检索式生成，功能与演示不受影响。

### 接口一览

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/health` | GET | 服务与语料状态（是否启用大模型） |
| `/api/eras` | GET | 11 个年轮节点数据 |
| `/api/people` | GET | 人物档案与关系 |
| `/api/archive?q=&era=` | GET | 史料库检索（按年代筛选） |
| `/api/ask` | POST | 智能体问答，`{"question":"…"}` → `{answer, citations, eraIds, engine}` |

## 六、合规与原创性说明

- **史料合规**：所有历史引用来自国家民委官网、中国共产党早期北京革命活动纪念馆展陈、《中央民族大学附属中学校史》、《内蒙古日报》/内蒙古新闻网、人民网·中国共产党新闻网、1919 年《晨报》、李大钊《庶民的胜利》授课讲义、《乌兰夫回忆录》、《蒙古农民》（1925）等公开来源，在“史料库”与作品说明中逐条标注。
- **年轮为叙事工具**：年轮圈数与历史年份的对应关系属于**艺术化呈现**，并非精确的科学定年结果；本作品在首页、页脚、史料库与作品说明中均明确标注。
- **枣树独白为原创**：第一人称叙事由团队撰写，其中光影、温度、掉落的枣子等细节为氛围营造，不构成史实陈述；史实依据逐条列于该年代的“史料卡片”。
- **图像素材**：当前所有画面均为**团队自制的程序化 SVG 示意插画（非历史照片）**，并在图注中标明；正式提交时替换为公开史料或官方展陈授权图片并注明来源。
- **字体/音频**：使用系统内置字体；语音朗读使用浏览器内置语音合成，不使用受版权保护的音频素材。
- **AI 使用披露**：`about.html` 第五节提供了《人工智能工具使用情况说明》填写模板（工具名称 / 使用环节 / 主要工作流 / 人工筛选修改），请按团队实际情况如实填写。
