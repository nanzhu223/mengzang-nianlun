# 触摸年轮

蒙藏学校旧址中华民族共同体数字记忆。

本仓库供团队共同搭建年轮交互网站，并将“问枣树”接入网站，提供历史问答、拟人故事讲述、史料引用与页面导览。

## 当前状态

仓库已初始化为私有仓库，默认分支为 main。现有网站代码、智能体代码及调研素材尚未上传；队友稍后邀请。

## 开发配合

- 网站负责年轮入口、年代内容页、人物长廊和史料库。
- 智能体通过后端API接入网站，结合观众当前查看的年代、人物或物件回答问题。
- 网站与智能体使用统一的史料编号和页面对应关系，历史引用保留出处及待核状态。

## 协作方式

1. 队友使用自己的GitHub账号，接受仓库协作邀请。
2. 开始修改前同步最新代码，按任务建立自己的功能分支。
3. 修改完成后提交Pull Request，确认后合并到 main。
4. 用Issues记录任务、问题和需要队友配合的事项。

邀请队友时，由仓库所有者进入 Settings → Collaborators 添加对方GitHub用户名。
