作品说明

《触摸年轮——蒙藏学校旧址中华民族共同体数字记忆》｜参赛赛道：指定命题“红色之旅 追梦铸魂”作品赛项

作品形态：网站（主体）＋ 智能体“问枣树”（创新点）＋ 演示视频 ＋ 作品说明。

一、选题背景与核心概念

1.1 选题来源

蒙藏学校旧址位于北京市西城区小石虎胡同 33 号，是中国共产党早期北京革命活动的重要场所，也是全国首个“中华民族共同体体验馆”所在地。 马克思主义在少数民族中的传播由此开始，这里是中国共产党历史上第一个由少数民族党员组成的党支部诞生地。

旧址西院中有一棵近 400 年树龄的大枣树，苍劲挺拔。这棵树“始植于清初”，见证了蒙藏学校从 1913 年建校到新中国成立后的全部历程。 李大钊、邓中夏、赵世炎等革命先驱曾在这棵树下与蒙藏学校的蒙古族青年学生们热烈交谈，传播马克思主义，启迪他们的思想。 1984 年 3 月 6 日，乌兰夫同志第四次回到母校，在这棵历经四百年沧桑的大枣树前，回忆起当年入党的情景，深情地说： “共产主义在少数民族中的传播，就是从这所学校开始的。”

这棵枣树不是一棵普通的树，它是历史的活体见证者。

1.2 核心概念

“年轮即历史”——以枣树的年轮作为时间轴，观众通过交互式年轮界面进入不同年代的历史场景，听枣树以第一人称讲述它见证的故事。 每一圈年轮对应一个关键历史节点，点击年轮即“进入”那个年代。枣树以亲历者的口吻叙事，将宏大的革命史转化为有温度的个人记忆。

核心叙述：红色火种点燃民族觉醒，新时代铸牢中华民族共同体意识。

二、史实依据与年轮节点

2.1 枣树真实性

枣树位于蒙藏学校旧址西院一进院和二进院之间，始植于清初，至今已有近 400 年树龄，多家权威媒体报道均确认了这一信息。

需要特别说明的是：年轮圈数与历史年份的对应关系属于艺术化呈现，并非精确的科学定年结果。 方案中所有历史场景均有史料依据，但“年轮圈”本身是叙事工具，这一点在本作品中明确标注（见各页脚注与史料库说明）。

本项目史料来源包括：中国共产党早期北京革命活动纪念馆官方展陈、蒙藏学校旧址专题展、《中央民族大学附属中学校史》、《内蒙古日报》等权威媒体报道、 人民网·中国共产党新闻网、国家民委官方网站。所有引用在“史料库”页面及本文档中逐条标注。

三、作品形式与功能设计

3.1 形式选择

核心作品：网站 ＋ 智能体 ＋ 视频 ＋ 作品说明。网站是主体作品，智能体是创新点，视频是展示与答辩材料。 IP 图样设计如时间允许可作为网站的视觉辅助元素，但不单独作为交付物。

3.2 网站功能设计

页面功能与实现
页面一：年轮入口页（首页）视觉主体为枣树横截面年轮图（SVG）；年轮上标注 11 个关键年份节点，鼠标悬停显示年份标签；点击任意年轮圈进入该年代内容页；页面底部为导航栏（年轮时间轴 / 人物长廊 / 史料库 / 关于我们）。外圈另设“老树发新芽”新时代视觉节点。
页面二：年代内容页（共 11 个）场景图（注明来源）、枣树独白（第一人称，200—300 字，可语音朗读）、史料卡片（2—3 条，逐条注明出处）、可点击的人物卡片与物件标签（弹窗显示详细信息）、前后导航（按钮 / ← → 方向键 / 手机左右滑动）。
页面三：人物长廊乌兰夫、多松年、荣耀先、吉雅泰、李裕智等人物卡片；点击卡片展开人物小传、与枣树的关系、相关史料；人物关系图谱用 ECharts 实现（谁介绍谁入党、谁和谁一起办刊）。
页面四：史料库按年代分类的史料条目，每条注明来源；支持关键词搜索（命中高亮）与年代筛选；与智能体联动——检索词可一键交给“问枣树”，智能体回答时引用史料库条目。

3.3 智能体设计

  • 名称：“问枣树”
  • 人设：一棵见证了中国近现代史近 400 年的枣树，语气温和、有历史感但不说教，始终以第一人称“我”说话。
  • 知识库：蒙藏学校史料、李大钊在蒙藏学校的活动、乌兰夫等人物事迹、《蒙古农民》刊物、第一个少数民族党支部。
  • 能力：①回答关于蒙藏学校历史的问题；②以枣树第一人称讲述历史故事；③引导观众探索网站其他模块（回答末尾给出“进入该年轮”的链接）。
  • 预设引导问题：“你在这里站了多少年？”“你见过李大钊吗？”“1923 年的那个冬天发生了什么？”……
  • 技术实现：采用 RAG（检索增强生成）架构——本地检索层对史料库 / 人物档案 / 枣树独白建立索引（中文 n-gram 加权召回），生成层可选两种模式：默认内置的“枣树语气”生成器（离线可用，答案严格取自召回史料并附出处）；也可在浏览器中配置 OpenAI 兼容大模型接口，将召回史料作为上下文交给大模型生成，形成完整 RAG 链路。所有回答都会列出所引用的史料条目与出处。
  • 入口：全站右下角“问枣树”悬浮按钮；史料库页可把检索词一键交给智能体。

四、技术路线

  • 前端：HTML / CSS / JavaScript；年轮交互使用 SVG（便于无障碍与响应式，亦可升级 Three.js 三维年轮）；人物关系图使用 ECharts；场景插画为程序化生成的 SVG 示意插画，便于统一替换为授权史料图片。
  • 后端（可选，见项目根目录 server.py）：Python Flask / FastAPI，提供史料库 API（/api/archive、/api/people）与智能体接口（/api/ask，同样为 RAG 架构：向量/关键词检索 + 大语言模型生成）。
  • 智能体：RAG 架构；未配置模型接口时使用本地检索式生成，配置后接入大语言模型，回答均带史料出处。
  • 部署：纯静态前端可直接双击 index.html 运行，也可在任意静态服务器（或 Flask）上部署，确保演示时可访问。
  • 年轮动画：年轮生长效果使用 SVG stroke-dashoffset 动画实现，核心交互不受开发周期影响。

5.2 史料合规

所有历史引用注明来源，逐条审核；不确定的内容不写入作品。作品在首页页脚、史料库、各年代页脚注中反复标注“年轮圈为叙事工具”的说明。

5.3 素材版权

历史照片优先使用公开史料或官方展陈图片并注明来源；本次展示版本中所有画面均为团队自制的程序化示意插画（非历史照片）， 并在图注中标明“示意插画·非历史照片”。字体、音效使用系统内置或开源授权资源；“听枣树讲”使用浏览器内置语音合成，不使用受版权保护的音频素材。

5.4 原创性

枣树独白、交互设计、智能体对话逻辑均为团队原创，不存在与往届作品实质性重复。
